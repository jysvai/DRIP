# DRIP (Driving Practice) — 한국 도로 운전 시뮬레이터 & 공개 주행 데이터셋

실제 한국 고속도로 구간을 브라우저 운전 게임으로 만들고, 사람들이 남긴 사고·아차사고·법규 위반 위치가 **실제 사고다발구간과 얼마나 일치하는지** 검증한다. 모은 데이터는 공개 데이터셋으로 낸다.

사이트: https://jysvai.github.io/DRIP/ · 운전하기: https://jysvai.github.io/DRIP/play/ · 차량 도감: https://jysvai.github.io/DRIP/play/garage.html

> 예전 iOS 운전 습관 앱(HAD v0.1)은 `_archive/had-ios-app/`에 보관돼 있다.

## 분석 축

**사람별 — 운전 패턴.** 시뮬 운전자가 한국 교통법규를 얼마나 지키고, 어떤 행동을 얼마나 자주 하는지 본다.
방향지시등 사용률과 켠 시점, 실선 침범, 제한속도 초과, 안전거리 2초 미만 비율, 급가감속 빈도를 잰다.
이걸로 운전 성향을 분류하고, 설문(DBQ)에서 본인이 답한 것과 실제 행동을 비교한다.

**구간별 — 위험 지점.** 사람들의 기록을 도로 1km 구간으로 모아 실제 사고 데이터와 비교한다.

1. 실제 사고가 잦은 1km 구간일수록 시뮬에서도 사고·아차사고 비율이 높다.
2. 실제 사고 원인 유형(과속, 안전거리 미확보 등)이 많은 구간에서 시뮬의 해당 위반도 많다.
3. (참고) 방향지시등 없는 차선 변경이 몰리는 구간을 따로 지도에 표시한다. 실제 사고 원인에는 진로 변경 항목이 없어서 직접 검증은 못 한다.

## 실행

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python pipeline\accident_hotspots.py   # 사고 1km 집계
.venv\Scripts\python pipeline\osm_roads.py           # 전국 고속도로 주행선 (OSM + 지형)
.venv\Scripts\python pipeline\network.py             # 주행선을 분기점에서 이어 경로 찾기용 도로망으로
.venv\Scripts\python pipeline\cameras.py             # 고속도로 단속 카메라·구간단속 (경찰청 표준데이터)
.venv\Scripts\python pipeline\osm_city.py            # 서울 시내 도로망 (OSM: 도로·신호·역·건물 이름)
.venv\Scripts\python pipeline\osm_city.py --region gyeonggi_east   # 경기 동부 국도 (+ 지형 격자·물)

cd game
npm install
npm run dev      # http://localhost:5173 (주행), /garage.html (차량 도감)
npm test         # 도로·차 물리·교통·법규 판정 테스트
npm run build
```

게임의 서버 연결은 `game/.env.local`에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`를 넣는다 (publishable 키만. secret 키는 절대 넣지 않는다).
배포 빌드는 저장소 변수(Settings → Variables)의 같은 이름 값을 쓴다.

### 주행 기록 적재 (연구 공개 전에는 꺼 둔다)

지금은 시험 운영이라 주행 기록을 서버(Supabase)와 R2에 쌓지 않는다. 기록은 결과 화면에서 JSON 파일로만 받을 수 있다. 공개할 때 세 곳을 켠다.

| 어디 | 끄기 (지금) | 켜기 (공개할 때) |
|---|---|---|
| DB 넣기 권한 (옛 페이지·직접 호출까지 막음) | `python pipeline/collection.py off` | `python pipeline/collection.py on` |
| 게임 빌드 | 저장소 변수 `VITE_DRIP_COLLECT` 없음 | `gh variable set VITE_DRIP_COLLECT --body on` 뒤 다시 배포 |
| R2 교통 원자료 | 저장소 변수 `R2_ARCHIVE` 없음 | `gh variable set R2_ARCHIVE --body on` (+ `R2_*` 비밀) |

`python pipeline/collection.py status`는 표마다 쌓인 행 수와 넣기 권한을 보여 준다. `supabase/schema.sql`을 다시 적용해도 권한은 켜지지 않는다.

### 이상한 주행 거르기 (데이터 품질)

현실에서 보기 어려운 주행은 데이터셋에 넣지 않는다. 기준은 `game/public/data/data_quality.json` 한 파일이다.
정체 도로에서 흐름을 무시한 질주, 제한속도보다 80km/h 넘는 폭주가 1분 넘게 이어지는 것, 잦은 충돌, 가드레일 타기, 갓길 질주, 세워 두고 방치, 조작 없음, 자동 운전이 여기에 든다.
최근 5번 중 3번 넘게 걸러진 참여자(브라우저)는 이후 주행도 올리지 않는다.
현실에도 있는 위험 운전(과속·앞차 바짝 따라가기·깜빡이 없는 차로 변경)은 연구 대상이라 거르지 않는다.

- 게임은 주행 중에는 브라우저에만 모으고, 끝난 뒤 검사(`game/src/log/quality.ts`)를 통과한 주행만 한꺼번에 올린다.
- 판정은 저장되는 1초 기록(흐름 속도 `flow_kmh`, 차로 수 `lanes` 포함)과 이벤트만으로 한다. 그래서 서버 쪽 재검사(`pipeline/quality.py`)가 같은 결과를 낸다. 브라우저 코드는 고칠 수 있으므로 분석(`compare_hotspots.py`)과 데이터셋 공개 전에 한 번 더 거른다.
- `python pipeline/quality.py`는 DB의 주행마다 판정하고 걸러진 이유별 수를 보여 준다. 기록이 쌓이면 이 비율을 보고 기준을 다시 맞춘다.

## 게임

메뉴에서 출발지·도착지(도시·나들목·분기점)를 넣으면 전국 고속도로망에서 가장 빠른 경로를 찾고, 경로의 주행선들을 분기점 연결로로 이어 하나의 도로로 만든다.
배속 없이 실제 시간으로 달리며, 위쪽 내비 안내(분기점 거리·차로 안내), 미니맵, 도착 예정 시각을 보고 분기점에서 갈아탄다. 목적지에 닿으면 주행이 끝나고 결과 화면이 나온다.

**시내 주행 (서울):** 메뉴에서 "시내 (서울)"을 고르고 역·건물·명소(예: 강동역 → 삼원타워)를 넣으면 서울 시내 큰길(간선·보조간선)로 길을 찾는다 (`game/src/city/`).
- **도로망:** OSM 도로 토막을 교차로(가까이 모인 교차점을 하나로)·한 방향 링크·이동(직진·좌회전·우회전)으로 바꾼다. 중앙분리대가 있어 두 줄로 그려진 큰길은 같은 이름·반대 방향 짝을 찾아 한 도로로 본다. 경로는 교차로 곡선으로 이어 한 줄 도로로 만들어 고속도로와 같은 물리·화면을 쓴다. 교차로 바닥은 접근로 끝마다 그 도로 높이에 닿게 삼각형으로 기울여 깔고, 들어오는 도로도 정지선 너머는 그 바닥에 맞춰, 비탈의 교차로에서도 길이 끊기거나 차가 바닥에 묻히지 않는다.
- **교차로:** 정지선·횡단보도·모서리 보도, 가로형 4색 신호등(적·황·좌회전 화살표·녹). 신호는 서울 간선도로에 흔한 동시신호(주도로 직진 → 주도로 좌회전 → 교차도로 직진 → 교차도로 좌회전, 전적색 2초. 황색은 접근 속도에 따라 50km/h 3초·60~70km/h 4초·80km/h 5초, 인지·반응 1초 + 3.05m/s²로 서는 시간인 ITE 식)이고 교차로마다 시작 시각이 다르다 (`city/signals.ts`). 우회전은 적색이어도 정지선에서 멈춘 뒤 돌 수 있다.
- **내비:** 도는 교차로만 1km·300m·직전에 음성으로 알리고("300미터 앞, ○○교차로에서 올림픽로 방향으로 좌회전입니다"), 500m 앞부터 돌 수 있는 차로를 보여 준다 (갈림길처럼 경로가 일부 차로로만 이어지는 곳은 곧게 갈 차로를). 오른쪽 목록은 다음 신호 교차로 셋, 미니맵은 둘레 시내 도로.
- **판정 (주행 중에는 안 보여 줌):** 신호 위반, 적색 우회전 전 일시정지 안 함, 정지선 넘어 정지, 회전·차로 변경 방향지시등 없음·늦음(30m, 도로교통법 시행령 별표2), 회전할 수 없는 차로에서 회전, 중앙선 침범. 교차로마다 `junction_pass`(신호 색·회전·차로)를, 황색이 켜진 순간 거리·속도와 통과·정지를 `signal_amber`로 남긴다 (딜레마 구간 분석용).
- **주변 차 (`city/traffic.ts`):** 경로 도로의 같은 방향·반대편 차는 고속도로와 같은 차로 모형(IDM·MOBIL, 한국식 습관·끼어들기)으로 달리고, 적색 신호에 정지선 앞에 줄을 선다. 교차로마다 일부는 경로를 벗어나 우회전·좌회전해 나가고, 옆 도로에서는 신호에 맞춰 건너오는 차가 나타나 경로 도로로 들어오거나 지나간다. 교차로 안에서는 이미 들어간 차가 먼저 가고(도로교통법 제26조), 길이 엇갈리면 만나는 곳에 먼저 닿는 차가 간다. 건너편 나갈 자리나 지나갈 길 위에 선 차(정지선을 넘어 코를 내민 차 포함)가 있으면 파란불에도 들어가지 않고(도로교통법 제25조 제5항, 꼬리물기로 교차로가 막히지 않게), 그래도 교차로 안에서 서로 길을 막아 15초 넘게 서면 비집고 빠져나간다. 선 플레이어와 코를 맞대고 서로 기다리면(플레이어 바로 앞에 선 차 포함) 6초 뒤 먼저 비켜 가고, 교차로 곡선에 25초(건너는 차는 60초), 끼어들지 못한 차로 끝에 20초 넘게 서 있는 차는 빼서 길이 영영 막히지 않게 한다. 합류하는 곳에서는 나란히 가던 플레이어가 먼저이고(통째로 뒤에 있으면 들어오는 차가 먼저), 건너는 차는 앞뒤 끝 가까이가 길 위에 오게 놓여 돌 때 긴 차 꽁무니가 옆 차로로 휘둘리지 않는다. 자동 운전도 교차로를 아직 건너는 차(늦게 들어간 화물차 등)와 길이 엇갈리면 같은 규칙으로 기다린다. 곧게 갈라지는 곳은 갈래가 놓인 쪽 차로에서 나가고(오른쪽 램프는 오른쪽 차로), 어느 방향으로도 못 가는 차로는 두지 않으며, 끝나는 차로 맨 앞의 차는 지퍼식으로 끼어든다. 적색 우회전은 멈춘 뒤 건너오는 차가 없을 때 돈다. 교통량은 메뉴의 교통 설정과 시간대를 따른다.
- **아직 없는 것:** 버스전용차로·보행자.

**국도 주행 (경기 동부):** 메뉴에서 "국도 (경기 동부)"를 고르면 강동구·하남·남양주·구리·양평의 국도·지방도·시군도(고속도로 빼고)로 길을 찾는다 (예: 강동역 → 두물머리는 천호대로·미사대로를 지나 6번 국도 경강로로 18km, 양평역 → 용문역). 시내와 달리 자동차전용 국도와 그 연결로도 달린다. 시내와 같은 도로망·신호·주변 차 모형을 쓰고 풍경과 도로가 다르다.
- **지형:** 지역 전체 75m 지형 격자(AWS Terrain Tiles)로 땅을 깔아 산·골짜기가 보이고, 도로는 40m마다 지형을 따라 오르내린다(다리·터널은 양 끝 사이를 곧게). 도로 옆은 둑·깎기로 지형에 이어지고, 분리대로 나뉜 상·하행은 두 차도 가운데 줄의 지형을 함께 써서 높이가 따로 놀지 않고, 그래도 높이가 다르면(실제로 멀리 떨어진 곳) 가운데가 옹벽이 된다. 가까운 900m 너머는 먼 산 한 장(100m 격자)으로 2.8km까지 그린다.
- **풍경:** 비탈은 숲(활엽수·침엽수 조림지), 평평한 골짜기는 논·밭·비닐하우스, OSM 물 면(한강·북한강·남한강)은 물. 시가지(OSM 주거·상업·공업 용도 땅, 서울 강동구 전체)와 이름 있는 곳이 모인 읍내에만 건물·보도·가로등이 있고(둘레가 거의 다 시가지인 도시는 시내만큼 높게, 마을·읍내는 낮게), 밖은 연석 없는 포장 갓길.
- **제한속도:** OSM에 없으면 도로교통법 시행규칙 제19조의 일반도로 기본값: 시가지·읍내(주거·상업·공업지역)는 50km/h, 그 밖은 편도 2차로 이상 80km/h·그 밖 60km/h. 신호는 OSM 신호등과 대로끼리 만나는 교차로. 교통량은 시내의 절반.

**요약 주행 (기본):** 경로 전체를 달리지 않고, 실제로 달리면 걸리는 시간의 약 12분의 1만 달린다 (1시간 경로면 5분, 서울→부산은 18분). 달리는 동안은 배속 없이 실시간 그대로다 (`game/src/sim/pacing.ts`).
- **꼭 달리는 곳:** 출발, 노선을 갈아타는 분기점(2.3km 앞 안내부터 연결로를 지나 합류 뒤 900m까지), 도착 앞 1.8km.
- **나머지 몫:** 사이 구간(2.2km씩)에 고르게 나누고, 나들목·공사·선 차·구간단속 시점이 가까우면 그쪽으로 당긴다. 구간을 고를 때 실제 사고 자료는 보지 않는다 (가상 핫스팟과 실제 핫스팟을 비교하는 연구라서).
- **시내·국도:** 출발, 도착 앞 600m와 사이 800m 구간들 (신호 교차로 쪽으로 당긴다). 짧은 길도 1.5km는 달린다. 교차로 안이나 정지선 60m 안으로는 내려앉거나 거기서 건너뛰지 않고, 다음에 돌 차로 쪽에 제한속도 이하로 놓는다. 건너뛴 시간은 제한속도에 신호 교차로마다 20초를 더해 잰다.
- **건너뛰기:** 구간이 끝나면 화면이 어두워지며 몇 km·몇 분을 건너뛰었는지, 다음 구간이 어디인지 보여 주고 같은 차로·비슷한 속도로 다음 구간 앞에 놓는다. 게임 속 시계와 도착 예정 시각은 건너뛴 시간만큼 흐른다.
- **기록:** 건너뛴 길에는 1초 샘플이 없으므로 핫스팟 노출·품질 거리 계산에 저절로 빠진다. 세션 `drive`에 주행 방식과 달린 구간을 남기고, 이벤트 `skip`에 건너뛴 거리·시간을 남긴다. 메뉴에서 "처음부터 끝까지"를 고르면 전체를 달린다 (`pace=full`).

**한국 도로다운 주변 차:** 택시·버스는 빠른 차로로 자주 끼어들고 급가속·급감속이 잦으며 방향지시등 없이 들어온다. 차선을 물고 달리는 차(K5·르노 계열에 조금 더), 1차로를 느리게 막는 차가 섞여 있고,
달린 시간 1~2.5분마다 옆 차로 차가 바로 앞으로 갑자기 끼어든다 (기록용 사건 `cut_in`, 뒤 5초의 아차사고는 플레이어 잘못으로 세지 않는다). 차선을 물고 달리는 차가 붙어 온 옆 아차사고(`cause: "line_ride"`)도 세지 않는다. 값과 근거는 `game/DATA.md`의 "한국 운전 특징".

**노면:** 보통 고속도로는 매끈해서 차가 떨지 않는다. 공사 구간과 눈 쌓인 길에서만 차체·화면·게임패드가 떨고 낮은 노면 소리가 난다 (`road/surface.ts` `roughnessAt`). 교량 신축이음(덜컥)과 갓길 노면요철(부르릉)은 그대로다.

**키보드 페달:** 진짜 페달처럼 밟아 둔 깊이가 유지된다. ↑를 누르는 동안 깊어지고(처음 0.4초는 천천히, 톡 치면 몇 %씩), 떼면 그 깊이로 계속 밟고 달려 속도·rpm이 한 자리에서 자리 잡는다. ↓는 먼저 가속 페달에서 발을 떼고, 계속 누르면 브레이크를 밟는다. 자동변속은 올리는 rpm과 내리는 rpm 사이를 벌려 정속 중 기어가 오르내리지 않는다. 예전처럼 누르는 동안만 밟히게 하려면 메뉴에서 "누르는 동안만" (`pedal=momentary`).

**핸들:** 키보드 핸들은 톡 치면 살짝(처음 0.15초는 천천히), 누르고 있으면 점점 크게 돈다. 도는 빠르기는 느릴 때(교차로) 빠르고 고속에서 느리며, 끝까지 꺾어도 옆 가속도가 고속 4m/s²·교차로 5.5m/s²를 넘지 않게 언더스티어까지 셈해 막는다 (메뉴 "조향 감도" 느리게·보통·빠르게, `steer=slow|fast`). 놓으면 가운데로 돌아오는 빠르기는 빠를수록 크다. "곡선에서 핸들 유지"(기본 켬, `hold=0`로 끔)는 키를 놓았을 때 차를 길 방향으로 세우고 굽은 길은 그 굽이만큼 핸들을 잡아 주되, 시내 교차로에서 도는 곳에서는 풀어서 저절로 돌지 않는다. 게임패드 스틱은 가운데 흔들림을 빼고 곱게 편 뒤 고속에서 덜 꺾이게, 레이싱 휠은 돌린 만큼 그대로 (휠 회전각 900°·540°·360°, 끝까지 돌리면 앞바퀴도 끝까지, 조향비 8~15:1). 휠 페달은 기기마다 축이 달라서 메뉴 "휠·페달 맞추기"로 밟아 보고 찾는다. 키보드와 게임패드·휠은 움직이는 쪽으로 저절로 바뀌고, 바뀌면 `input_switch` 이벤트, 세션 `drive`에 조향 설정과 출발할 때 장치를 남긴다.

**운전 보조:** 요즘 차에 있는 만큼만 넣었다. 판정이 아니라 차의 기능이다.
- **차로 유지 보조 (LKA, 기본 켬, L키):** 시속 60km부터 방향지시등 없이 차선을 넘으려 하면(0.7초 뒤 차 옆면이 선을 넘으면) 경고음(넘으려는 쪽)·진동을 주고 운전대를 살짝 돌려 되돌린다 (`game/src/sim/assist.ts`). 힘은 약해서 운전자가 그쪽으로 크게 꺾으면 경고만 한다. 작동할 때마다 `lka_assist` 이벤트를 남긴다.
- **후측방 화면 (BVM):** 방향지시등을 켜면 그쪽 사이드미러 아래 카메라 화면이 계기판 원(왼쪽은 속도계, 오른쪽은 회전계) 자리에 뜬다. 운전석 시점에서는 차 안 계기판 화면에도 같이 뜬다. 방향지시 화살표는 1.6Hz로 딸깍 소리와 함께 깜빡이며 빛이 번진다.
내비는 한국어 음성으로도 안내한다 (분기점 2km·1km·직전, 제한속도 변경, 과속 단속 카메라, 구간단속 시점과 평균 속도). 카메라 위치는 경찰청 표준데이터에서 가져왔다 (`pipeline/cameras.py`).
날씨는 맑음·흐림·비·폭우·짙은 안개·눈·폭설 중에서 고른다. 비·안개·눈에는 법정 감속(젖은 노면·눈 20mm 미만 20%, 가시거리 100m 이내 50%)으로 판정하고, 젖은 노면은 제동거리가 약 1.8배, 눈길은 약 3배로 늘어난다 (`game/DATA.md`). 눈이 오면 땅·나무에 쌓이고 앞유리에 눈송이가 붙는다. 새벽 결빙을 고르면 다리 위·터널 출구 뒤가 군데군데 얼어(블랙아이스) 제동거리가 약 7배가 되고, 긴 다리 앞마다 결빙 주의 안내가 뜬다. 운전석 시점에서는 앞유리에 빗방울이 맺히고(빠를수록 많이, 큰 방울은 맞바람에 위로), 와이퍼가 비에는 간헐·폭우에는 빠르게 닦는다. 달리는 차는 뒷바퀴로 물보라를 튀기고(트럭·버스는 더 크고 짙게), 앞차 물보라에 앞이 뿌예진다. 밤에 비가 오면 전조등·미등이 젖은 노면에 길게 비친다.
고장·사고로 선 차(비상등, 안전삼각대, 대피한 운전자)도 나오고, 그 옆을 몇 km/h로 얼마나 떨어져 지나갔는지 기록한다 (2차사고 위험 행동).
길에는 공사 구간도 나온다 (차로 하나를 라바콘으로 막고 화살표 작업 차량을 세움, 임시 제한 80km/h). 실시간 공사 정보를 붙이기 전까지는 시간대·요일별 빈도로 놓는다 (`game/DATA.md`).
차량은 79가지 중에서 고른다. 무게·엔진(가솔린·디젤·대형 디젤·전기)·속도제한장치가 차종마다 다르고, 화물·대형승합은 화물차 제한속도와 지정차로, 버스는 버스전용차로 규칙을 따른다.
경로 주행 기록의 `s`는 이어 붙인 도로 기준이고, 세션의 `route`(조각별 원래 주행선·위치)로 원래 주행선 위치로 되돌린다 (`compare_hotspots.py`가 자동으로 한다).

그래픽은 자동·낮음·보통·높음·최고 중에서 고른다 (`game/src/render/world.ts`의 `QUALITY`). 기본은 자동이다.

| 단계 | 그리는 거리 | 나무 | 그림자 | 해상도 배율 상한 | 밤 빛 번짐 |
|---|---|---|---|---|---|
| 낮음 | 1.5km | 4할, 가까운 곳만 제 모양 | 없음 (계단 현상 방지도 끔) | 1 | 없음 |
| 보통 | 2km | 6할 | 1024, 차 둘레 ±55m | 1.25 | 없음 |
| 높음 | 2.6km | 7.7할 | 2048, ±70m | 1.75 | 있음 |
| 최고 | 3.3km | 전부, 800m까지 제 모양 | 4096, ±110m | 2 | 있음 |

- **첫 단계:** 자동은 그래픽 카드 이름으로 첫 단계를 짐작한다. 내장 그래픽은 보통, 외장은 높음, RTX 3060급 이상은 최고다.
- **맞추기:** 출발 전 대기 화면에서 GPU까지 기다려 잰 한 프레임 시간으로 단계를 올리거나 내린다. 결과는 브라우저에 저장해 다음 주행에 쓴다 (`render/gfx.ts`).
- **주행 중:** 프레임이 50fps 아래로 떨어지고 실제 일도 무거우면 해상도를 조금씩 낮춘다. 그래도 느리면, 자동일 때만 단계를 내리고 알린다. 모니터 주사율이나 절전 모드로 fps만 낮은 경우는 건드리지 않는다.

검수용 주소: `/play/?road=r1-1&km=20&cam=chase&hour=22&preset=실제&weather=rain&auto=1`, `/play/?from=서울&to=강릉&car=tractor_40ft`, `/play/?city=seoul&from=강동역&to=삼원타워` 처럼 붙이면 메뉴 없이 바로 시작한다
(`auto=1`은 자동 운전, `pace=full`은 요약 없이, `lka=0`은 차로 유지 보조 끄기, `pedal=momentary`는 키보드 페달을 누르는 동안만, `steer=slow|fast`는 조향 감도, `hold=0`은 곡선에서 핸들 유지 끄기, 이렇게 연 주행은 서버에 올리지 않음). 조작법은 게임에서 F1.

API 키가 필요한 단계부터는 `.env.example`을 `.env`로 복사해 값을 채운다.

- 매일 자동 수집: `.github/workflows/traffic.yml`이 매일 06:40(한국 시간)에 전날 자료를 받아 커밋하고 사이트를 다시 올린다. 저장소 비밀 `EX_API_KEY`가 있어야 돈다:
  `gh secret set EX_API_KEY` (붙여 넣기). `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`을 넣고 저장소 변수 `R2_ARCHIVE=on`까지 두면 AVC 원자료(차로별·차종별 속도)를 R2에 쌓는다 (공개 전에는 두지 않는다).
  날씨(Open-Meteo)는 키가 없어도 매일 받는다. `gh secret set ITS_API_KEY`도 넣으면 같은 시각의 돌발상황을 받아 `events/latest.json`으로 올린다 (its.go.kr 오픈API 신청 때 '돌발상황정보'를 고른다, 승인 3~5일).
- 도로공사 방향: E = 이정이 느는 쪽(종점 방향), S = 기점 방향. 경부선은 기점이 부산이라 E = 서울 방향.
- VDS 좌표가 비어 있는 노선(수도권제2순환선 일부, 세종포천선)과 민자 고속도로는 아직 기준점이 없다.
