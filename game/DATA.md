# 게임 데이터 파일

게임 속 교통·운전 습관·법규·차종은 모두 `public/data/`의 JSON 파일에서 읽는다. 코드를 고치지 않고 이 파일만 바꾸면 게임이 바뀐다.
고친 뒤에는 `npm test`로 형식을 검사한다 (`src/data.test.ts`).

| 파일 | 내용 | 지금 값 |
|---|---|---|
| `driver_profiles.json` | 운전 성향 (택시·버스·화물차·경차·초보·난폭 등)과 차종별 배정 | 한국 통계·연구 + AVC 실측 기반, 일부 가정 (`basis`, `sources`) |
| `traffic_defaults.json` | 교통량 단계, 시간대별 교통량, 차종 구성 | 가정값 |
| `rules_kr.json` | 플레이어 주행을 판정하는 한국 고속도로 법규 | 법 조문은 확인, 위험운전 수치는 확인 필요 |
| `vehicles.json` | 차종 76가지 (크기, 최고속도, 가속, 도색, 번호판, 교통 속 비율) | 제원 기반 |
| `cameras.json` | 고속도로 과속 단속 카메라·구간단속을 주행선 위치(s)로 옮긴 것 (`pipeline/cameras.py`) | 경찰청 무인교통단속카메라 표준데이터 (2026-05 기준, 고정식 94대·구간단속 124곳) |
| `../traffic/latest.json` | 전날 실제 교통 (`pipeline/traffic_ex.py daily`가 만든다) | 도로공사 AVC 실측 (36개 주행선) |

## 한국 운전 특징 넣기 (`driver_profiles.json`)

### 운전 성향 (`profiles`)

차 한 대가 생길 때마다 아래 값을 **정규분포 [평균, 표준편차]**에서 하나씩 뽑는다. 같은 성향이라도 차마다 조금씩 다르게 달린다.

| 항목 | 뜻 | 단위 | 모형 |
|---|---|---|---|
| `speedFactor` | 원하는 속도 = 제한속도 × 이 값 (차종 최고속도를 넘지 않음) | 배 | IDM v0 |
| `timeHeadway` | 앞차와 두려는 시간 간격 | 초 | IDM T |
| `minGap` | 정지했을 때 앞차와 간격 | m | IDM s0 |
| `accelScale` | 차종 최대 가속도에 곱하는 값 | 배 | IDM a |
| `comfortDecel` | 평소 감속 | m/s² | IDM b |
| `politeness` | 차로를 바꿀 때 뒤차 피해를 얼마나 신경 쓰는지 (0 = 신경 안 씀) | 0~1 | MOBIL p |
| `changeThreshold` | 차로를 바꿀 만큼의 이득 | m/s² | MOBIL Δa_th |
| `keepRightBias` | 오른쪽 차로로 돌아가려는 성향 | m/s² | MOBIL 비대칭 |
| `safeDecel` | 끼어들 때 뒤차에게 허용하는 최대 감속 (클수록 칼치기) | m/s² | MOBIL b_safe |
| `signalUse` | 차로를 바꿀 때 방향지시등을 켜는 비율 | 0~1 | |
| `signalLead` | 방향지시등을 켜고 옮기기 시작할 때까지 | 초 | |
| `laneChangeTime` | 차로 변경에 걸리는 시간 | 초 | |
| `designatedLaneCompliance` | 지정차로(대형차 오른쪽 차로)를 지키는 비율 | 0~1 | |
| `busLaneCompliance` | 버스전용차로를 비워 두는 비율 | 0~1 | |
| `passingLaneStay` | 1차로에서 앞지르기 뒤 오른쪽으로 돌아갈 때까지 머무는 시간 | 초 | |

새 성향을 추가하려면 `profiles`에 이름을 하나 더 만들고 모든 항목을 채운다.

한국 자료를 찾아 다시 잡았다. 성향마다 어떤 값이 측정(D)·유도(R)·가정(A)인지는 파일의 `basis`, 출처 목록은 `sources`에 있다.

| 값 | 근거 |
|---|---|
| 방향지시등 사용률 (승용 보통 0.80, 택시 0.55, 버스·화물 0.60) | 차로변경 방향지시등 미준수 42.4% (안실련·삼성교통안전문화연구소 2026), 사업용 71% vs 비사업용 30% 좌회전 위반, 국토부 2017 차로변경 사용 71% |
| 방향지시등을 켜고 옮기기까지 (보통 3.0±1.2초) | 켠 차의 약 21%가 직전에 짧게 켬 → 2초 미만이 20%가 되게 |
| 차간시간 (보통 1.35초) | 도로용량편람 기본구간 용량 2,200pcphpl → 평균 차두 1.64초에서 차 길이·정지 간격을 빼서 |
| 밤 차간시간 ×1.1 | 안전거리 준수 주간 약 1/3, 야간 약 50% (현대해상 교통기후환경연구소, 도로공사 CCTV) |
| 평소 감속 (보통 1.8m/s²) | DTG 급감속 기준 2.08m/s²(7.5km/h/s) 아래에서 대부분 제동하게 |
| 원하는 속도 | AVC 한산할 때 승용 0.985, 버스 0.958, 대형화물 1.051(화물 제한속도 대비, 90km/h 제한장치로 상한) |
| 지정차로 준수 (대형화물 0.90, 버스 0.94) | AVC 2026-09-21, 경찰대 2006 관측 (대형승합 1차로 위반 6.34%) |
| 9인승 승합의 버스전용차로 (0.5) | 전용차로 승합차의 약 99%가 탑승 기준 미달 (한국ITS학회 2022). 0.5 자체는 가정 |

승용 성향 비율(보통 0.6·여유 0.17·공격적 0.15·초보 0.08)은 직접 근거를 못 찾아 가정값으로 둔다.
`validationTargets`(승용 1차로 점유 편도 3차로 0.44, 차간거리 0.6×속도 이상 비율 주간 0.33·야간 0.5, 방향지시등 약 72%, 대형화물 지정차로 0.90)에
게임 교통이 가깝게 나오도록 맞추는 것이 다음 일이다.

"1차로 정속 주행"(`passingLaneCruise`, 추월 목적 없이 1차로를 계속 달린다는 자기보고 편도 3차로 35%)은 따로 넣었다. 이런 운전자는 오른쪽으로 돌아가지 않고 1차로로 옮기려 한다.

게임 교통으로 잰 값 (시험 도로, 차로당 12대/km, 10분, 2026-09-22):

| 항목 | 게임 | 목표 |
|---|---|---|
| 방향지시등 켜고 차로 변경 | 0.66~0.69 | 약 0.72 |
| 대형화물 지정차로 (편도 3·4차로) | 0.86~0.93 | 0.90 |
| 승용 1차로 점유 (편도 3차로) | 0.33 | 약 0.41 (AVC 교통량 비율 0.44를 차로별 속도로 나눠 밀도로 바꾼 값) |
| 차간거리 ≥ 0.6×속도(km/h) m 비율 (앞차 150m 안) | 0.58~0.63 (밤 0.72) | 주간 약 0.33, 야간 약 0.5 |

승용 1차로 점유는 화물차가 얼마나 섞였는지에 따라 달라진다. 화물 비율을 높이면(승용 0.5·화물 0.5) 승용 차로 이용이 1·2·3차로 0.43·0.36·0.21로 실측(0.44·0.34·0.22)과 거의 같아진다.
대형화물은 앞지르기 뒤 `passingLaneStay` 동안만 2차로에 머물면 2차로 점유가 6~24%로 실측 42%보다 낮다.
그래서 대형화물의 `passingLaneCruise`(0.6)를 "앞지르기 차로를 달리는 차로로 쓰는 비율"로 넣었다. 이 운전자는 편도 3차로에서 2차로로 옮겨 그대로 달린다
(지정차로를 안 지키는 10%는 1차로까지). 시험 도로 6회 평균으로 대형화물 1·2·3차로 점유 0.02~0.09·0.36~0.38·0.54~0.62, 실측 약 0.10·0.42·0.48.
이렇게 달리는 것은 법으로는 지정차로 위반이라, 플레이어가 화물차로 2차로를 30초 넘게 달리면 위반으로 잡힌다.
차간거리는 게임이 실제보다 넉넉하다. 비교 조사의 교통량을 몰라서 밀도 조건을 맞추지 못했다.

### 누가 어떤 성향인지 (`assignment`, `typeOverrides`)

- `assignment`: 차종 분류(승용, SUV, 전기차, 택시, 버스, 화물, 특수)마다 성향 비율. 예: `"택시": {"taxi": 0.85, "standard": 0.15}`
- `typeOverrides`: 특정 차종만 따로. 예: 1톤 트럭은 `light_commercial`, 스포츠카는 `aggressive`를 더 많이.
  차종 id는 `vehicles.json` 또는 차량 도감(`/play/garage.html`)에서 확인한다.

비율은 합이 1이 아니어도 된다 (상대 비율로 뽑는다).

### 도로공사 실측으로 채우기 (`pipeline/habits_avc.py`)

`pipeline/traffic_ex.py daily`가 남긴 AVC 원자료(차로별·차종별 15분 교통량·속도)로 계산한다.

```
python pipeline/habits_avc.py           # 계산해서 보여 주기만 (data/processed/habits/에 저장)
python pipeline/habits_avc.py --apply   # driver_profiles.json에 넣기 (calibration에 출처·날짜·바뀐 값이 남는다)
```

| 측정 | 넣는 곳 |
|---|---|
| 한산할 때 승용차 속도 ÷ 제한속도 | 승용 계열 성향(standard·calm·aggressive·novice·taxi)의 `speedFactor` 평균 (서로 간격은 그대로 두고 함께 옮김) |
| 버스, 소형화물(1~2.5톤), 대형화물 속도 ÷ 제한속도(대형화물은 화물차 제한속도) | `bus_driver`, `light_commercial`, `truck_heavy`의 `speedFactor` |
| 대형화물이 앞지르기로도 못 가는 왼쪽 차로에 있는 비율 | `truck_heavy.designatedLaneCompliance` |
| 차로 수별·차종별 차로 이용 비율과 차로별 속도, 승용차 1차로 비율 | 보고서에만 (keepRightBias·passingLaneStay는 이 비율이 게임에서 비슷하게 나오도록 맞춘다) |

2026-09-21(월) 하루치 예: 한산할 때 승용 0.985, 버스 0.958, 소형화물 0.914, 대형화물 1.051(화물차 제한속도 대비),
대형화물 지정차로 준수 약 0.90, 편도 3차로에서 승용차의 44%가 1차로. 이 값은 위 근거 표와 함께 손으로 반영했다. 평일·주말을 며칠 모은 뒤 `--apply`로 다시 맞춘다.
차간 시간, 끼어들기 간격, 방향지시등 사용률은 15분 집계로는 알 수 없어 아래 자료나 게임 기록으로 채운다.

### 데이터로 채울 때 참고할 곳 (예시)

- 차간 시간 간격, 속도 분포: 도로공사 VDS 개별 차량 자료, 고속도로 교통량 조사
- 방향지시등 사용률: 교통안전공단·도로교통공단 교통문화지수 조사
- 지정차로·버스전용차로 위반: 경찰청 단속 통계
- 차종별 속도·급가감속: 운행기록장치(DTG) 분석 보고서 (화물·버스·택시)

값을 바꾸면 `status`와 `note`에 출처와 날짜를 적는다.

## 교통량 (`traffic_defaults.json`)

- `presets`: 메뉴의 한산/보통/혼잡/정체. 차로 1개, 1km당 차 대수.
- `hourlyFactor`: 0~23시. 메뉴에서 "시간대 반영"을 고르면 `보통 × 이 값`.
- `composition`: 차종 분류 비율. 분류 안에서 어떤 차종이 나올지는 `vehicles.json`의 `share`로 정한다.
- `oppositeDensityFactor`: 반대편 차로 교통량 비율.

`traffic/latest.json`(수집기가 만든 전날 실제 교통)에 그 주행선이 있으면 메뉴에 "실제 교통 (날짜)"가 생기고 주행선 목록에 "실측"이 붙는다.
형식은 `src/sim/config.ts`의 `RealTraffic`:

| 항목 | 뜻 |
|---|---|
| `roads.<주행선>.density[24]` | 시간대별 차로 하나 1km당 대수. 측정 지점마다 교통량 ÷ 속도 ÷ 차로 수를 내고 중앙값 |
| `roads.<주행선>.speed[24]` | 시간대별 평균 속도 (km/h) |
| `roads.<주행선>.composition` | AVC 12종 → 게임 분류. 1종(승용·미니트럭)은 승용·SUV·전기차·택시를 기본값 비율로 나누고, 2종 = 버스, 3~12종 = 화물 |
| `roads.<주행선>.sites[]` | 측정 지점별 `s`(주행선 시작점부터 m), `km`(도로공사 이정), `lanes`, `density[24]`, `speed[24]` |

게임은 출발 위치에서 30km 안의 가장 가까운 측정 지점 값을 쓰고, 없으면 주행선 전체 값을 쓴다.
AVC 원자료에는 차로별·차종별 속도가 있어서 화물차가 어느 차로로 얼마나 빨리 달리는지(지정차로 준수)도 뽑을 수 있다 (R2 `raw/ex/avc15/`).

## 법규 (`rules_kr.json`)

규칙마다 `enabled`로 끄고 켤 수 있고, 기준값과 근거(`source`)가 있다.
판정 결과는 주행 중에는 보여 주지 않고 결과 화면과 데이터셋에만 남긴다 (알려 주면 평소 습관이 기록되지 않는다).

| 규칙 | 기준 |
|---|---|
| 과속 | 제한속도 + `toleranceKmh`를 `minDurationSec` 넘게 |
| 최저속도 | 앞이 막히지 않았는데 최저속도 미만 |
| 방향지시등 | 차로 변경 `leadDistanceM`(100m) 전에 켜지 않음 |
| 안전거리 | 앞차와 `thresholdSec`(2초) 미만인 시간 비율, `criticalSec`(1초) 미만이 이어지면 기록 |
| 급가속·급감속 | 1초에 `kmhPerSec` 이상 (확인 필요) |
| 1차로 계속 주행 | `maxDistanceM` 넘게 1차로 |
| 터널 안 차로 변경, 갓길 주행, 버스전용차로 | 있으면 기록 |
| 아차사고 | 충돌까지 `ttcSec` 미만, 옆 간격 `lateralGapM` 미만, 또는 내 차 때문에 다른 차가 `inducedBrakeMs2` 넘게 제동 |

| 단속 카메라 (`enforcement`) | 고정식 카메라를 제한속도 + `cameraToleranceKmh`(10, 가정) 넘게 지나면 적발, 구간단속은 시점~종점 평균 속도가 + `sectionToleranceKmh` 넘으면 적발 |

### 단속 카메라 (`cameras.json`)

경찰청 표준데이터의 고속국도 카메라 510건(차로별로 따로 올라온 것 포함)을 주행선에 옮겼다. 방향은 설치장소 글("목포방향", "(구리→포천)")에 나온 곳이
그 주행선 앞쪽에 있는지로 정하고, 글이 없으면 더 가까운 주행선, 그것도 애매하면 양쪽에 넣는다. 구간단속은 시점과 종점을 짝지어(구간 길이가 있으면 길이가 맞는 쪽) 만든다.
데이터의 방향 코드와 구간 길이 단위(km·m)가 기관마다 달라 글과 거리를 먼저 믿는다.

실제 내비처럼 게임도 카메라 600m 앞, 구간단속 시점 1km 앞에서 알려 주고, 구간단속 중에는 평균 속도를 보여 준다. 적발 여부는 주행 중에는 알려 주지 않는다.
실제 운전자도 내비 안내를 듣고 달리므로, 카메라 앞에서만 속도를 줄였다가 다시 올리는 습관(이른바 캥거루 운전)도 기록에 그대로 남는다.

버스전용차로 구간은 `busLane.sections`에 노선 번호·시작/끝 나들목 이름·요일·시간·차로로 적는다. 나들목 이름이 주행선 밖에 있으면 `fromPlace`/`toPlace` 도시 쪽 끝을 쓴다.

## 차종 (`vehicles.json`)

| 항목 | 뜻 |
|---|---|
| `body` | 3D 모양 (`src/render/vehicleModels.ts`에 있는 것 중 하나) |
| `length`, `width`, `height`, `wheelbase` | m |
| `paint` | 팔레트 이름 또는 색 목록 |
| `plate` | `white`(비사업용), `yellow`(사업용), `ev`(전기·수소) |
| `heavy` | 대형차 (지정차로, 화물차 제한속도, 후부 반사판) |
| `extras`, `sign`, `livery`, `cargo`, `axles` | 택시 표시등, 경광등, 도색, 적재물, 축 수 |
| `maxSpeed`, `accel` | km/h, m/s² |
| `share` | 같은 분류 안에서 나오는 비율 |
